# 营养光谱画（Nutrition Spectrum）

把一餐的六项营养数值变成一张可直接分享的图。**这是一个渲染技能：数值来自真实营养库，不做任何美化性改写。**

## 什么时候用

- 「我今天吃了板烧、玉米杯和纯牛奶，画个营养光谱」
- 「把这单做成光谱图」「看看这餐营养够不够」
- 点餐类应用需要一张营养达成率卡片

如果用户想要音频/音乐 → 用 `nutrition-melody`。

## 怎么跑

```bash
# 自然语言
python scripts/spectrum.py "我今天吃了板烧、玉米杯和纯牛奶" -o 我的营养光谱.png

# 结构化输入（推荐：点餐场景，避免别名歧义）
python scripts/spectrum.py --codes 1406:1,4437:1,3755:1 -o 我的营养光谱.png

# 多餐合并成日谱
python scripts/spectrum.py "早饭脆薯饼加牛奶，午饭板烧加玉米杯" --day -o 日谱.png

# 只要纯光谱，不要饼图
python scripts/spectrum.py "板烧和可乐" --no-pie -o 纯光谱.png
```

Windows 上 `python` 不可用时，用 WorkBuddy 托管解释器：  
`C:\Users\wiskey\.workbuddy\binaries\python\envs\default\Scripts\python.exe`

参数：

| 参数                      | 说明                                    |
| ----------------------- | ------------------------------------- |
| 位置参数 `TEXT`             | 自然语言餐品描述，可含「早饭/午饭/晚饭/下午茶/夜宵」分隔        |
| `--codes 1406:1,4437:2` | SKU 编码:数量，优先于文本                       |
| `-o/--out`              | 输出 PNG 路径，默认 `营养光谱_<时间戳>.png`         |
| `--no-pie`              | 不画饼图（纯光谱版）                            |
| `--day`                 | 按餐次切分并合并成日谱（多峰）                       |
| `--time`                | 指纹时间，ISO 格式，如 `2026-10-19T23:50`，默认当前 |
| `--name`                | 自选铭文（名字/数字/颜色），参与指纹，落在图上印章处           |
| `--price`               | 显示金额，默认自动                             |
| `--label`               | 餐次标签，默认「一餐」                           |
| `--json`                | 只输出 JSON 摘要（供程序调用）                    |

脚本最后会打印一段 JSON：六项数值、达成率、饼图占比、输出路径、指纹前缀。**汇报给用户时用自然语言转述这个 JSON，不要贴原始 JSON。**

## 图长什么样（定稿，不要自己改）

- 谱带顺序：碳水 → 糖 → 蛋白质 → 脂肪（宏量区）｜钠 → 钙（微量区），两区之间一条竖向虚线
- 段宽 = 该营养素在这一餐里的存在感；谱高 = 达成率；谱色 = 各营养素本色
- 峰高必须与标注百分比严格一致（段中心余弦插值），不要改成高斯叠加
- 右上角马卡龙饼图 + 灰边（160,160,160），图例在饼图右侧动态居中
- 落款：价格 · 日期时刻；糖字段官方库没有，图上明示「糖为推算值（碳水×0.35）」

## 口径（必须如实转述）

- 达成率基准是**全日参考摄入量**（钙 1000mg、钠 2000mg、蛋白质 60g、脂肪 70g、碳水 300g、糖 50g），所以一餐的达成率天然偏低，这不是「不合格」。
- 糖 = 碳水 × 0.35 的推算值，官方营养库无糖字段，**不要当成实测值**。
- 未匹配到的餐品会进 `unmatched`，如实告诉用户「这几样没识别出来」，不要静默丢弃。

## 唯一性

同一餐在不同时刻、不同措辞、不同自选铭文，图的相位/笔触/色偏/颗粒/印章会不同，**但六项营养数值绝不改变**。这就是「同餐不同时」的实现方式：事实层锁定，渲染层随指纹漂移。

## 依赖

仅 `numpy` + `Pillow`。引擎在项目根目录（`nutrition_core.py` 解析与聚合、`spectrum_toy.py` 渲染），本 skill 的脚本会自动向上找到引擎目录，不复制引擎代码。
