# 营养旋律（编曲规划师工作流）

你在这里扮演的角色是**编曲规划师**：先出配器规划单，再按单合成，最后校验交付。不是"直接调函数出一堆音"。

## 工作流（按顺序执行，不要跳步）

1. **读谱面**：解析餐品 → 六项达成率（碳水/糖/蛋白质/脂肪/钠/钙）。
2. **出配器规划单**：跑 `scripts/arrangement_sheet.py`，得到编号为 `ARR-YYYYMMDD-NNN` 的规划单 Markdown。规划单包含成品定位、配器层次表、段落结构、收尾三段式、连贯性措施、验收清单。给用户看一眼规划要点（不用贴全文）。
3. **按单合成**：跑 `scripts/melody.py` 生成 WAV。
4. **校验**（硬性验收，不达标必须修）：
   - 结尾无硬切：最后 1 秒能量必须平滑衰减（对比最后 0.25s 两半的 RMS）；
   - 无长静音尾：实际有声长度 ≈ 文件长度（脚本自动裁剪）；
   - 无削波：peak ≤ 0.95 × 满幅；
   - 时长 10~22 秒。
5. **交付说明**：输出三件套——专业版映射表（每个音乐要素 ← 哪个营养数值）、大众版一句话概括、JSON（`schema: nutrition-melody/1.1`）。

## 映射口径（三曲风统一，事实层不许改）

1. **调式** = 钠钙比（钠≥80% 且钙<50% → 小调色彩；否则大调/明亮）
2. **BPM** = 能量达成率 × 各曲风基准：民乐 80+r×38、爵士 96+r×30、摇滚 114+r×36
   （三档速度必须听得出差别，否则三种曲风会像同一首歌换音色）
3. **引子** = 三甲营养素的音程签名（起音级 = 第一名达成率×2.5 + 能量档位 0/1/2；第二名定跳进方向与幅度；第三名定回落深度）。**每餐的引子必须不同**——这是"开头听起来不一样"的关键，曲风各自保留自己的引子形态：
   - 民乐：长音 + 滑音，可上行可下行（含"落腔"感）
   - 爵士：弱起上行三连音 pickup（短-短-长，抢在正拍前）
   - 摇滚：根音 + 四度强力和弦点弦两下（切分、干脆）
4. **乐句顺序** = 与光谱同序：碳水→糖→蛋白质→脂肪→钠→钙
5. **句长** = 2.6 + 达成率×2.2 拍（微量项约 2.4 + r）
6. **音级** = 达成率×8（越高越饱满）
7. **力度** = 0.50 + 0.36×达成率
8. **句尾** = 三曲风必须不同：民乐每句下沉二级（落腔）、爵士上行/下行句交替（问-答）、摇滚每句落回 riff 根音
9. **结尾** = 钙 <50% → 悬置不落主音（民乐二度、爵士九音、摇滚上扬二音）；≥50% → 级进落主音
10. **装饰音插位** = 交互指纹第 16–20 位（同一餐不同时刻 → 不同装饰，曲子独一无二）

糖 = 碳水×0.35 推算，说明里必须注明。

## 三曲风规范（配器表的唯一来源）

|       | 民乐 minyue                      | 爵士 jazz                                | 摇滚 rock                                   |
| ----- | ------------------------------ | -------------------------------------- | ----------------------------------------- |
| L1 主奏 | 二胡（奇次谐波鼻音+6.2Hz 揉弦+滑音+弓噪）      | 电钢琴（Rhodes tine 质感：强 2/4 泛音+5.4 倍非谐钟声） | 重失真电吉他（锯齿双吉他失谐→tanh drive 7.5→箱体低通）       |
| L2 铺底 | 古筝 2 拍一组五声琶音（4 种 pattern 轮换）   | 行走贝斯（根→三→五→经过音，每拍换音）                   | 强力和弦 riff（根+五+八度，I-V-vi-IV，八分 chug）       |
| L3 律动 | 梆子/木鱼（强拍 0.13/中 0.055/弱 0.035） | 刷鼓（swing hat + 2/4 brush snare）        | 鼓组（kick 四踩+第 3 拍半双踩+snare 2/4+每 2 小节三连填充） |
| L4 空间 | 房间混响 0.11/0.23/0.37s           | 同左                                     | 尾奏延音和弦 + 全局 1.6s 淡出                       |
| 律动性格  | 正拍下压                           | Swing 2:1 反拍重音                         | 正拍推进                                      |
| 和声    | 五声音阶                           | 大七/九和弦（避免小三阴郁）                         | Power chord（无三音，天然积极）                     |
| 情绪    | 欢快/温暖                          | 轻盈/暖洋洋                                 | 热血/阳光                                     |

配器原则：L1 与 L2 音区错开一个八度避免同频掩蔽；L3 只做标记不抢主奏；L4 不压缩保留余韵。

## 怎么跑

```bash
# 一步到位（合成 + 说明 JSON）
python scripts/melody.py "我今天吃了板烧、玉米杯和纯牛奶" --style minyue -o 我的旋律.wav

# 结构化输入
python scripts/melody.py --codes 1406:1,4437:1,3755:1 --style rock -o 我的旋律.wav

# 先出配器规划单（写入 md）
python scripts/arrangement_sheet.py "板烧、玉米杯、纯牛奶" --style jazz -o 配器规划单.md
```

参数两脚本一致：`TEXT` / `--codes` / `--style minyue|jazz|rock` / `--time` / `--name`（铭文）/ `--label` / `--price`。  
`melody.py` 额外有 `--json-out`（说明 JSON 路径）、`--md-out`（专业版+大众版 Markdown 路径）。

Windows 上 `python` 不可用时，用 WorkBuddy 托管解释器：  
`C:\Users\wiskey\.workbuddy\binaries\python\envs\default\Scripts\python.exe`

## 汇报口径

- 用大众版一句话开头（脚本输出 JSON 的 `plain` 首段），再给 3~5 条核心映射（BPM/调式/最长句/结尾处理），配器描述随曲风换。
- 结尾悬置要说清因果："钙只有 33%，曲子停在半空，提醒下次补杯奶"。
- 唯一性话术："同一份餐骨架相同，装饰音位置专属于这一刻"。

## 合规备注

全部音色由正弦/锯齿/噪声波形合成，无任何第三方采样素材，不涉及录音制品邻接权。本 skill 提供过程辅助，不构成法律意见。

## 依赖

仅 `numpy`（纯波形合成出 WAV）。引擎在项目根目录（`nutrition_core.py` / `melody_style.py` / `melody_minyue.py` / `melody_jazz.py` / `melody_rock.py`），脚本自动向上定位，不复制引擎代码。
